Entry for the [One-Line Office Joke Laugh-Off](https://make.fun/competitions/u-suzy-one-line-office-joke-laugh-off-f574ac73) on make.fun.

## The joke

> Our AI assistant wrote my performance review, gave me 4 out of 5, and my manager copied it without reading it.

## How it works

`main.py` is deterministic: it writes the single one-line joke above to `/output/entry.txt` on every run. No randomness, no network, no files read from outside this repository.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
